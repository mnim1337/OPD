# OPD

Настольная программа для оценки уже выполненных опытов маршрутизации в многоспутниковых системах связи. Исходное [ТЗ-ОАМ-01 v1.0](requirements/ТЗ_Оценка_маршрутизации_единый_документ.docx) принято пользователем как рабочая редакция 23.10.2026. Версия кода — в [VERSION](VERSION), изменения — в [CHANGELOG](CHANGELOG.md).

Программа читает четыре файла одного опыта (`experiment.json`, `packets.csv`, `routes.csv`, `channels.csv`) либо принимает ручной ввод, рассчитывает К0–К3, показывает результаты и хранит версии черновиков и оценок. Демонстрационный [профиль Ω](configs/examples/profile_demo.json) предназначен только для синтетических контрольных наборов. Программа не исполняет исследуемый алгоритм маршрутизации и не создаёт наблюдения вместо ПАК.

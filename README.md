# OPD

Проект настольной программы для комплексной оценки алгоритмов маршрутизации в многоспутниковых системах связи.

- [Исходное ТЗ](requirements/ТЗ_Оценка_маршрутизации_единый_документ.docx) — ТЗ-ОАМ-01, версия 1.0; пользователь подтвердил её как текущую итоговую редакцию 23 октября 2026 г.
- [План работ по главам ТЗ](requirements/tasks.md) — задачи, зависимости и критерии готовности.
- [План разработки](docs/development/development-plan.md) — последовательность поставок, контрольные точки и открытые решения.
- [Матрица требований](requirements/traceability.md) и [сценарии приёмки](docs/development/acceptance-scenarios.md) — состав проверок по ТЗ.
- [Открытые решения](requirements/open-questions.md) и [рабочие численные допуски](docs/development/numerical-test-plan.md) — вопросы до приёмки.
- [Исходные контрольные материалы](requirements/source-materials.md) — состав и назначение архивов.
- [Понимание предметной области](understanding.md) — подтверждённые сведения и открытые вопросы.

Текущая версия `0.3.0` реализует ввод, расчёт К0–К2 из GUI и CLI, сохранение и просмотр результатов, экспорт JSON/CSV и резервное копирование. Графики, серии, PDF и восстановление резервной копии остаются в работе этапа 4; Windows `.exe` относится к этапу 6. [Установка и проверки](docs/development/setup.md) · [Руководство по вводу](docs/user-guide/data-entry.md) · [Расчёт и результаты](docs/user-guide/calculation.md) · [Алгоритм](docs/algorithms/k0-k2.md). Язык — Python, GUI — PySide6/Qt Widgets.

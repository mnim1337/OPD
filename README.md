- [Исходное ТЗ](requirements/ТЗ_Оценка_маршрутизации_единый_документ.docx) — ТЗ-ОАМ-01, версия 1.0, проект для согласования.
- [План работ по главам ТЗ](requirements/tasks.md) — задачи, зависимости и критерии готовности.
- [Понимание предметной области](understanding.md) — подтверждённые сведения и открытые вопросы.

Исходного кода программы в репозитории пока нет. Контрольные архивы, упомянутые в ТЗ, в репозитории отсутствуют.

# OPD

Проект настольной программы для комплексной оценки алгоритмов маршрутизации в многоспутниковых системах связи.

- [Исходное ТЗ](requirements/ТЗ_Оценка_маршрутизации_единый_документ.docx) — ТЗ-ОАМ-01, версия 1.0; пользователь подтвердил её как текущую итоговую редакцию 23 октября 2026 г.
- [План работ по главам ТЗ](requirements/tasks.md) — задачи, зависимости и критерии готовности.
- [План разработки](docs/development/development-plan.md) — последовательность поставок, контрольные точки и открытые решения.
- [Матрица требований](requirements/traceability.md) и [сценарии приёмки](docs/development/acceptance-scenarios.md) — состав проверок по ТЗ.
- [Открытые решения](requirements/open-questions.md) и [рабочие численные допуски](docs/development/numerical-test-plan.md) — вопросы до приёмки.
- [Исходные контрольные материалы](requirements/source-materials.md) — состав и назначение архивов.
- [Понимание предметной области](understanding.md) — подтверждённые сведения и открытые вопросы.

Текущая версия `0.4.0` реализует ввод и расчёт К0–К2 из GUI и CLI, сохранение и просмотр результатов, фоновой запуск с запросом отмены, графики, сопоставление оценок, серии, JSON/CSV/PNG, резервное копирование и восстановление. П02–П04 и П04а сверены по тексту и композиции с рисунками В.4–В.7: загрузка показывает назначение четырёх файлов и фактическое число записей, а неполный комплект не открывается в редакторе. Паспорт открыт в девяти формах по приложению В, с таблицами повторяемых записей и расширенным вводом JSON. У П05 появились заголовки отдельных форм и компактное меню служебных действий. П06 получил вкладки с собственными заголовками, компактную таблицу рядом с радаром, пояснения без сырого JSON на первом плане и отметки пропусков на Ганте. П07 содержит фильтры и подробные строки сохранённых оценок. Визуальная сверка вспомогательных состояний и Windows-проверка ещё не завершены. Этап 4 продолжается: интерфейсный цикл требует ручной приёмки; PDF ожидает согласования шаблона. Windows `.exe` относится к этапу 6. [Установка и проверки](docs/development/setup.md) · [Руководство по вводу](docs/user-guide/data-entry.md) · [Расчёт и результаты](docs/user-guide/calculation.md) · [Алгоритм](docs/algorithms/k0-k2.md). Язык — Python, GUI — PySide6/Qt Widgets.

Для расчёта нужен профиль Ω: загрузите согласованный JSON через «Загрузить Ω». Для синтетических контрольных опытов приложен [демонстрационный профиль](configs/examples/profile_demo.json); его шкалы не утверждены для реальных данных.

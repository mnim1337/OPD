## Доказательства и ограничения

- После объединения веток `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q` — 82 passed на Linux/Python 3.12.3. Покрыты повторный импорт, восстановление незавершённого черновика, отказ закрытия серии, проверки К0–К3 и предыдущие сценарии.
- PyInstaller 6.11.1 собрал текущие Linux-варианты `opd` и `opd-gui`. Упакованный CLI выполнил `check` и `calculate` на исходном контрольном ZIP (40 пакетов, 8 маршрутов, 156 строк каналов), создал `assessment.json`; GUI оставался запущенным через пять секунд в Qt offscreen. Это проверка упаковки текущего кода на Linux, не результат Windows workflow.
- `scripts/smoke_windows.ps1` исправлен по фактическому составу контрольного ZIP: четыре файла находятся в корне. `scripts/build_windows.ps1` теперь проверяет код каждой нативной команды, версию и разрядность Python, наличие обоих `.exe`. Workflow на Windows Server 2022 x64 должен выполнить тесты, сборку и smoke перед загрузкой артефакта.
- Успешный удалённый запуск Windows workflow, визуальная проверка GUI на Windows 10/11 и предельный согласованный набор ещё не подтверждены. Поэтому DEL-01 и AT-25 не переводятся в «подтверждено»; Q-06/Q-07 остаются открытыми.
- Все 84 строки матрицы пересмотрены после объединения. Подтверждено по группам: GEN 0/5, BASE 2/4, UI 11/12, DATA 2/4, MAN 2/6, PROF 3/4, CALC 8/10, RUN 6/6, OUT 9/12, SAVE 3/8, QUAL 3/8, DEL 1/5.

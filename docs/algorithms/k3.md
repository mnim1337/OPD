# К3: чувствительность и повторения

**Источник:** ТЗ-ОАМ-01 версии 1.0, приложение Б, формулы (3.47)–(3.56), OUT-11–OUT-12 и AT-20. Реализация: `src/scanner/core/sensitivity.py`, `repeats.py`. Расчёт доступен без GUI через CLI. Пять предоставленных контрольных опытов имеют разные сценарии и не образуют выборку повторов.

## Чувствительность

Для двух сопоставимых опытов с одним профилем Ω сначала рассчитываются точные К0–К2. При неточном физическом показателе или итоге К3 отказывает и не подставляет середину интервала. Функция `max_scale_slope` берёт максимум абсолютных наклонов между соседними опорами, в обратной физической единице показателя (3.47). Сумма `100 × w_i × L_i × |P_i(A₁)−P_i(A₂)|` ограничивает изменение балла при фиксированных шкалах и весах (3.48).

Параметр `epsilon_weight_l1` задаёт радиус изменения вектора весов по норме L1. Возвращаются границы `50 × epsilon_weight_l1` для одного балла (3.49), сумма физической и весовой границ (3.50), фактическая разность итогов (3.51) и `100 × epsilon_weight_l1` для изменения разности (3.52). Положительная разность, превышающая последнюю границу, даёт достаточное условие сохранения преимущества первого опыта; аналогично для отрицательной разности. В остальных случаях статус `inconclusive` не означает смену предпочтения. Вектор весов должен оставаться неотрицательным с единичной суммой; изменённые опоры шкал требуют нового расчёта.

```bash
opd sensitivity path/to/first path/to/second --profile path/to/profile.json --epsilon-weight 0.1 --output sensitivity.json
```

Числа JSON записаны десятичными строками без экранного округления. Проверка сопоставимости сравнивает условия сети, трафика, запланированные воздействия и методику наблюдения; отличающиеся фактические исходы допустимы. Общий рейтинг при несопоставимости не формируется.

## Повторы

`opd repeats` принимает отдельные четырёхфайловые комплекты одного сценария, алгоритма, настройки и профиля Ω. У каждого должен быть уникальный `experiment_id` и `repeat_id`; совпадение серии или разные ID сами по себе не доказывают независимость. К0–К2 выполняются для каждого комплекта, затем усредняются **итоговые баллы** (3.53), а не физические показатели перед нормализацией (3.54). При `n ≥ 2` выдаются выборочная дисперсия и стандартное отклонение (3.55). Для одного опыта разброс не определён.

```bash
opd repeats path/to/run1 path/to/run2 --profile path/to/profile.json --output repeats.json
```

При документированном основании независимости можно добавить `--independence-basis 'описание отдельных случайных запусков'`; тогда выдаётся условная стандартная ошибка среднего `s/√n`. Текст основания сохраняется в JSON и не является автоматической проверкой независимости. Интервал Стьюдента (3.56) не рассчитывается: нужны отдельное обоснование независимости и распределения, выбранный доверительный уровень и соответствующий квантиль. Фактических независимых повторов ПАК пока нет.

# Расчётное ядро К0–К2

**Источник:** ТЗ-ОАМ-01 версии 1.0, § 5 и приложение Б. Подробное соответствие формулам и единицам приведено в [описании алгоритма](../algorithms/k0-k2.md).

```text
папка четырёх файлов ── read_folder ── Experiment ── validate_experiment
                                                │
профиль Ω ───────────────────────────────────────┼── calculate
                                                │      ├── prepare: К0
                                                │      ├── calculate_raw: К1
                                                │      └── score: К2
                                                └── Assessment → JSON через CLI
```

`src/scanner/core/runner.py` предоставляет чистую функцию `calculate(experiment, profile)`. Она не обращается к Qt, файловой системе или хранилищу, не меняет вход и возвращает `Assessment`. Чтение файлов и запись JSON выполняет `src/scanner/cli.py`. Проверка входа останавливает расчёт при блокирующих диагностических ошибках. Допустимая неполнота передаётся в показатели и сохраняется статусами и границами.

`prepare.py` собирает временное окно, истории состояний, события, маршруты и физические проверки пути. `indicators.py` получает семь исходных показателей и трассы их расчёта. `scoring.py` проверяет профиль, вычисляет экспертные веса, нормализует показатели, создаёт частные и групповые баллы и итог. `types.py` хранит значение вместе с единицей, статусом, открытостью и неограниченностью границ. Для арифметики используется `Decimal` в локальном контексте с точностью 50 знаков; JSON сохраняет числа строками без экранного округления.

Чистые функции К3 в `sensitivity.py` и `repeats.py` повторно используют К0–К2 и проверку сопоставимости. Они не изменяют вход и не сохраняют результаты в SQLite; команды CLI записывают JSON по запросу. [Описание К3](../algorithms/k3.md) фиксирует формулы и предпосылки. Диспетчер К0–К2 и GUI остаются отдельными потребителями ядра. [ADR-0002](../decisions/0002-time-uncertainty-in-core.md) описывает временное ограничение для ненулевой погрешности часов.

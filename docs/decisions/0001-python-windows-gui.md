# ADR-0001. Python и PySide6 для настольного интерфейса Windows

**Дата:** 23 октября 2026 г.

**Статус:** принято для планирования реализации; сборка и работа `.exe` ещё не проверены.

## Контекст

ТЗ-ОАМ-01 § 1 и § 11.3 требует настольное приложение с русскоязычным GUI, но оставляет язык и библиотеку интерфейса на согласование. Пользователь 23 октября 2026 г. выбрал Python, поставку Windows `.exe` и поручил выбрать GUI-библиотеку. Интерфейс содержит много редактируемых таблиц, вкладок и состояний; расчётное ядро должно оставаться отдельным от GUI (ТЗ, § 3, § 6).

## Решение

- Использовать **PySide6 (Qt Widgets)** для основного окна, панелей, форм и таблиц. Для больших таблиц проектировать модели данных через `QTableView`/`QAbstractItemModel`, не связывая ядро с виджетами.
- Планировать сборку Windows `.exe` через официальный `pyside6-deploy`; окончательный режим поставки и воспроизводимые команды закрепить после проверки на целевой Windows. Документация Qt описывает как каталог с `.exe` и зависимостями, так и режим единого файла.
- Зафиксировать версии Python, PySide6 и инструмента сборки при создании приложения. Итоговый пакет проверять на согласованной версии Windows, включая запуск, импорт, расчёт, сохранение и экспорт.

## Основания и последствия

PySide6 — официальные Python-привязки Qt; Qt Widgets предоставляет модель представления для редактируемых таблиц. Qt поддерживает сборку Windows-приложения через `pyside6-deploy`. Это даёт подходящую основу для П01–П07 и таблиц П05 без второй реализации расчётов в интерфейсе. Придётся проверять состав пакета, лицензии используемых компонентов и фактическую работу собранного `.exe` до поставки.

# Проект сценариев AT-01–AT-25

Источник: ТЗ-ОАМ-01 версии 1.0, § 10, приложение А и [матрица требований](../../requirements/traceability.md). Это спецификация будущих проверок, а не протокол испытаний. Для каждого исполнения протокол должен содержать commit/версию сборки, вход и его версию, действия, ожидаемый и фактический результат, статус и диагностику. Изменяемые фикстуры создавать из копий контрольных комплектов; исходные архивы не править.

## Протокол AT-06, 28 октября 2026 г.

Версия исходного кода: `0.5.0`, commit `827a170`; среда: Linux, Python 3.12.3. Вход: отдельная копия четырёх файлов `PAK_export_reference_4files_v1.zip` для каждого случая. Действие: изменить версию паспорта, заголовок или строку CSV, размер пакета, `flow_id` либо `link_id`, затем вызвать `read_folder`. Для изменений содержимого CSV без нарушения структуры контрольные сумму и размер в паспорте обновляли, чтобы проверить именно значение. Ожидание: отказ импорта с кодом, адресом и способом исправления. Факт: все пять категорий отклонены; версия указывает `experiment.json`/`schema_version`, остальные случаи указывают CSV и строку; поле указывается, когда применимо. Проверка: `test_import_rejects_unknown_version_and_wrong_csv_header` и `test_at06_import_rejects_bad_values_with_addressed_diagnostics`, **успешно**.

Отдельно `test_observed_failure_loss_and_no_route_are_valid_input` подтвердил отсутствие ошибок валидации у зарегистрированных отказа канала, потери пакета и отсутствия маршрута. Это часть QUAL-02, но не полный протокол этого требования.

## Протоколы AT-19 и AT-21, 28 октября 2026 г.

Версия кода `0.5.0`, проверяемые commit `12afcc9` и `c5a3ee4`, Linux/Python 3.12.3; оба сценария **успешны**.

- **AT-19:** вход — копии эталонного опыта с разной сетью либо заданным составом потоков и пара с одинаковыми условиями. Действия — вычислить причины сопоставимости и открыть окно сравнения. Ожидание и факт — для различающихся условий показана причина без общего рейтинга, для одинаковых условий показан статус сопоставимости. Доказательства: `test_comparability_ignores_measured_outcomes_but_checks_conditions`, `test_comparison_view_explains_incomparable_conditions_without_ranking`.
- **AT-21:** вход — эталонный опыт и две версии демонстрационного Ω с изменённой опорой шкалы, затем два разных синтетических опыта в одной серии. Действия — рассчитать и сохранить оценки, открыть старую запись, добавить следующий опыт через GUI. Ожидание и факт — новая оценка ссылается на Ω v2, старая остаётся связанной с Ω v1 и прежним payload; два опыта имеют разные входные данные и оценки. Доказательства: `test_new_profile_version_keeps_previous_assessment`, `test_next_experiment_keeps_distinct_inputs_and_results_in_same_series`.

Остальные протоколы и статусы ведутся в [матрице требований](../../requirements/traceability.md). Рабочие допуски приведены в [плане численных проверок](numerical-test-plan.md); их утверждение для окончательной приёмки остаётся открытым.

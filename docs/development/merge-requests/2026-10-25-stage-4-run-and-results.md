## Проблема и результат

После этапа 3 пользователь мог рассчитывать К0–К2 только через CLI, а GUI сохранял лишь черновики. Добавлен диспетчер, который проверяет вход и Ω, фиксирует их точные версии, рассчитывает сохранённый снимок и добавляет результат в SQLite. GUI показывает контекст, семь показателей, группы, итог и статусы; историю можно открыть без пересчёта. Добавлены JSON/CSV-экспорт и согласованная резервная копия хранилища. После ошибки записи можно повторить запись результата без повторного запуска ядра.

Это промежуточная поставка этапа 4. Полный пользовательский цикл П01–П07, серии, графики, сравнение, анализ чувствительности, повторы, PNG/PDF и восстановление резервной копии ещё не реализованы. Расчёт пока синхронный, без отображения прогресса и отмены. PDF ожидает решения Q-05.

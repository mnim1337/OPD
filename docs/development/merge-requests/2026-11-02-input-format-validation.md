# MR: проверка формата ввода 1.0.0

**Исходная ветка:** `feat/input-format-validation-audit`. **Целевая ветка:** `feat/manual-input-result-verification`. **Код:** `d56e487`. **Уровень:** минорный, `0.6.3 → 0.6.4`.

**Проблема.** Паспорт проверял только часть фиксированных правил `file_contract`; многопутевой набор мог содержать повторный `path_id` или неизвестные доли; повреждённый параметр изменения события мог привести к исключению вместо диагностики.

**Поведение.** Проверяются все фиксированные поля контракта 1.0.0. Многопутевой набор требует нескольких различных путей, известных долей с суммой 1; адрес ошибки содержит строку и поле. Параметры события `link_up` и `capacity_bps` проверяются до сопоставления с историей каналов. Импорт и ручной ввод используют общую семантическую проверку; байтовые условия импорта остаются частью файлового парсера.

**Требования:** DATA-02, DATA-04, QUAL-01–03, AT-06. [Оценка](../../../benchmarks/statistics/assessments/2026-11-02-input-format-validation.md): **54/84 = 64,29%, +1,19 п. п.** к сопоставимой оценке. QUAL-02 подтверждено; остальные перечисленные DATA/QUAL требования остаются частичными по причинам в оценке.

**Проверки:** `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q` — **101 passed**; `git diff --check` — без замечаний. Синтетические контрольные входы импортируются и экспортируются. Новых измерительных экспериментов не было.

**Документация:** обновлены `CHANGELOG.md`, `docs/architecture/data-entry.md`, `understanding.md`, `requirements/traceability.md` и оценка. Дополнительная актуализация архитектуры, пользовательских и эксплуатационных инструкций для этого локального исправления не требуется.

**Ограничения:** семантика повторного использования `route_set_id` между непересекающимися интервалами не определена приложением А; полный аудит вложенного паспорта и нагрузочные/отказные сценарии остаются открытыми. Контрольный комплект синтетический; реальная ПАК-выгрузка и Windows-приёмка не проверялись. Независимая приёмка итогового commit перед merge ещё требуется.

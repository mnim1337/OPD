## Проблема и результат

Для MAN-02 отсутствовало отдельное копирование всей записи журнала. Добавлена кнопка «Копировать запись» для пакетов, маршрутов и каналов: полная строка вставляется рядом и может редактироваться отдельно. На Ганте удалена общая подпись установленного пути, которая перекрывала отдельные участки с разным физическим состоянием.

Сквозная проверка сопоставляет формы, импорт, расчёт К0–К2, экспорт четырёх файлов и повторный импорт контрольного комплекта. Отдельно проверены автопривязка `experiment_id`, пустые измерения, метаданные экспорта, фактический момент события и цвета участков Ганта. Алгоритм расчёта не менялся.

# MR: титульная панель П01 по рисунку В.3

**Исходная ветка:** `fix/title-page-spec`. **Целевая ветка:** `feat/input-format-validation-audit`. **Код:** `26e5df4`. **Уровень:** минорный, `0.6.4 → 0.6.5`.

**Проблема.** Титульная панель отличалась от рисунка В.3: текст располагался около вертикального центра, орбитальная схема была мала, фон плоским; служебная строка нарушала полноэкранную композицию. Пользователь исключил из визуальной сверки три пояснительные подписи макета.

**Поведение.** П01 размещает заголовок, описание и кнопку слева по пропорциям В.3; крупная орбитальная схема и звёздный градиент занимают правую часть. Композиция масштабируется с окном. Кнопка «Начать» сохраняет переход в П02; строка состояния скрыта только на П01.

**Требования:** UI-02, UI-12. [Оценка](../../../benchmarks/statistics/assessments/2026-11-02-title-page.md): **54/84 = 64,29%, 0,00 п. п.** к предыдущей сопоставимой оценке. UI-12 остаётся частичным до Windows-сверки всего приложения.

**Проверки:** `QT_QPA_PLATFORM=offscreen .venv/bin/python -m pytest -q` — **101 passed**; `git diff --check` — без замечаний. Снимок `outputs/ui-review/start-title-revised.png` просмотрен локально и не включён в Git. Измерительных экспериментов не было.

**Документация:** обновлены `README.md`, `CHANGELOG.md`, `docs/user-guide/data-entry.md`, `understanding.md`, `requirements/traceability.md` и оценка.

# Данные опыта и черновики: руководство этапа 2

Запуск: `opd-gui` после установки по [инструкции разработки](../development/setup.md). Текущий интерфейс предназначен для подготовки данных к будущему расчётному ядру. Расчёт семи показателей и панели результатов появятся на следующих этапах.

1. **Импорт 4 файлов.** Выберите папку, содержащую ровно `experiment.json`, `packets.csv`, `routes.csv`, `channels.csv`. Программа проверит версию 1.0.0, формат, связи и интервалы. Оригинальные байты сохраняются с черновиком после нажатия «Сохранить черновик».
2. **Новый.** Открывается пустой паспорт с полями формата и три пустые таблицы. Программа не создаёт пакеты, маршруты, события или счётчики. В дереве паспорта дважды щёлкните значение или тип для редактирования. Кнопка «Добавить поле/элемент» создаёт вложенный объект или строку массива; для узлов, каналов, потоков, событий и проверок подставляется пустой шаблон полей. Пустое значение хранится как `null` в JSON или как пустая ячейка CSV, наблюдавшийся ноль вводится отдельно.
3. **Таблицы.** Вкладки «Пакеты», «Маршруты» и «Каналы» позволяют добавлять и удалять строки, копировать и вставлять прямоугольные диапазоны через буфер обмена. `experiment_id` берётся из паспорта для всех строк и потому скрыт в таблицах. Время вводится в секундах, скорость в бит/с, объём в байтах. Ячейка `path_links` содержит JSON-массив направленных `link_id`, например `["L_A_B","L_B_C"]`.
4. **Профиль Ω.** Вкладка хранит семь шкал и веса. Можно загрузить отдельный JSON-профиль кнопкой «Загрузить Ω»; демонстрационный профиль из исходного архива предназначен только для контрольных расчётов. Профиль сохраняется вместе с черновиком, а его версия меняется только при изменении содержимого.
5. **Проверка и сохранение.** «Проверить данные» показывает код, место, поле и причину ошибки. Неполный набор можно сохранить черновиком, закрыть программу и восстановить через «Открыть черновик». Каждое сохранение создаёт новую версию; старые версии остаются в хранилище. При выходе с несохранёнными правками предлагается сохранить, уйти без сохранения или отменить действие.
6. **Экспорт 4 файлов.** Выберите пустую папку. Экспорт доступен для данных без блокирующих ошибок; паспорт записывается последним. Для ручного или исправленного импортированного набора `data_origin` становится `manual_prepared`; первоначальные импортированные байты остаются в хранилище черновика.

Черновики GUI по умолчанию находятся в `~/.opd/drafts.sqlite3`. Не следует вручную менять этот файл во время работы приложения. Для переноса или резервного копирования пока закройте программу и копируйте файл целиком; отдельная функция резервного копирования предусмотрена этапом 4.

Текущий редактор паспорта и профиля представляет вложенные поля деревом. Он даёт доступ ко всем значениям и повторяемым объектам, но ещё не реализует специализированные локальные подформы и подсказки для каждого поля П05 из ТЗ; они относятся к доработке интерфейса. Проверка крупной реальной выгрузки и Windows-сборки также ещё не проводилась.

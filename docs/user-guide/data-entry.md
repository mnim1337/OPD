# Данные опыта и черновики: руководство этапа 2

Запуск: `opd-gui` после установки по [инструкции разработки](../development/setup.md). В редакторе доступны импорт и правка входа, сохранение черновика и Ω, проверка, экспорт, запуск К0–К2, история результатов и резервное копирование хранилища. Описание запуска и ограничений результатов приведено в [руководстве по расчёту](calculation.md).

Начните с титульной страницы П01. Кнопка «Начать» откроет главное меню П02, затем «Эксперименты» — П03 с карточками нового опыта, продолжения работы и просмотра результатов. «Справка» и «О программе» открывают отдельные страницы С01 и С02; кнопка внизу возвращает в главное меню. На П04 выберите загрузку четырёх файлов либо ручной ввод. Тексты и структура П02–П04а сверены с рисунками В.4–В.7 приложения В ТЗ; полное соответствие остальных форм ещё дорабатывается.

На П07 сохранённые оценки перечислены в таблице с алгоритмом, сценарием, повтором, моделью, состоянием и итогом I(A). Поиск фильтрует строки по видимым полям; выпадающие списки ограничивают таблицу по модели и состоянию. Выберите строку и нажмите «Открыть выбранную оценку». Поиск с пустым результатом не открывает скрытую запись. Черновики продолжаются отдельным действием «Продолжить черновик».

1. **Импорт 4 файлов.** На П04 нажмите «Выбрать комплект», затем на П04а — «Выбрать папку». Папка должна содержать ровно `experiment.json`, `packets.csv`, `routes.csv`, `channels.csv`. П04а показывает назначение файлов, наличие и число записей трёх CSV из выбранного комплекта; размер и SHA-256 принятого файла доступны в подсказке к строке. Программа проверяет версию 1.0.0, формат, связи и интервалы. Отсутствующий файл отмечается в таблице; прочие ошибки показываются сообщением. До успешной проверки «Открыть данные» недоступно. После успешного выбора нажмите «Открыть данные». Оригинальные байты сохраняются с черновиком после нажатия «Сохранить черновик».
2. **Новый.** Выберите «Открыть формы ввода»: откроется пустой П05 с паспортом и тремя пустыми таблицами. Программа не создаёт пакеты, маршруты, события или счётчики. В паспорте девять вкладок по приложению В: «Общие сведения», «Среда», «Узлы», «Соединения», «Потоки», «События», «Наблюдение», «Проверки», «Полнота». Заголовок показывает выбранную форму. Простые поля редактируются прямо в карточках. Для узлов, соединений, потоков, событий и проверок выберите запись в таблице слева и измените её поля справа; кнопки под списком добавляют, копируют и удаляют записи. Меню «Действия» в шапке содержит импорт, экспорт, историю, серии, резервное копирование и «Расширенный ввод паспорта» для дополнительных полей JSON. Ошибочное числовое значение подсвечивается и блокирует сохранение до исправления. Пустое значение хранится как `null` в JSON или как пустая ячейка CSV, наблюдавшийся ноль вводится отдельно.
   На «Общих сведениях» поля контрольной суммы, настроек и примечания к алгоритму открываются кнопкой «Настройки алгоритма и контрольная сумма» в карточке реализации; изменения сразу входят в паспорт.
3. **Таблицы.** Вкладки «Пакеты», «Маршруты» и «Каналы» позволяют добавлять и удалять строки, копировать и вставлять прямоугольные диапазоны через буфер обмена. `experiment_id` берётся из паспорта для всех строк и потому скрыт в таблицах. Время вводится в секундах, скорость в бит/с, объём в байтах. Ячейка `path_links` содержит JSON-массив направленных `link_id`, например `["L_A_B","L_B_C"]`.
4. **Профиль Ω.** Вкладка хранит семь шкал и веса. Перед расчётом загрузите согласованный JSON-профиль кнопкой «Загрузить Ω» либо заполните вкладку. Для синтетических контрольных опытов доступна копия исходного демонстрационного профиля: `configs/examples/profile_demo.json`; его шкалы не предназначены для оценки реальных измерений. Новый черновик содержит пустой профиль; «Проверить данные» и «Запуск расчёта» сообщат, если он не заполнен. Профиль сохраняется вместе с черновиком, а его версия меняется только при изменении содержимого.
5. **Проверка и сохранение.** «Проверить данные» показывает код, место, поле и причину ошибки. Неполный набор можно сохранить черновиком, закрыть программу и восстановить через «Открыть черновик». Каждое сохранение создаёт новую версию; старые версии остаются в хранилище. При выходе с несохранёнными правками предлагается сохранить, уйти без сохранения или отменить действие.
6. **Экспорт 4 файлов.** Выберите пустую папку. Экспорт доступен для данных без блокирующих ошибок; паспорт записывается последним. Для ручного или исправленного импортированного набора `data_origin` становится `manual_prepared`; первоначальные импортированные байты остаются в хранилище черновика.

Черновики GUI по умолчанию находятся в `~/.opd/drafts.sqlite3`. Не следует вручную менять этот файл во время работы приложения. Используйте пункты «Создать резервную копию» и «Восстановить копию» в меню «Действия»; восстановление проверяет файл перед заменой текущего хранилища.

Паспорт представлен формами, повторяемые объекты — списком и деталями; профиль Ω по-прежнему редактируется деревом. Оформление П05 требует окончательной сверки каждого поля и состояния с макетами приложения В на Windows. Проверка крупной реальной выгрузки и Windows-сборки ещё не проводилась.

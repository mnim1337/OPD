# Данные опыта и черновики: руководство этапа 2

Запуск: `opd-gui` после установки по [инструкции разработки](../development/setup.md). В редакторе доступны импорт и правка входа, сохранение черновика и Ω, проверка, экспорт, запуск К0–К2, история результатов и резервное копирование хранилища. Описание запуска и ограничений результатов приведено в [руководстве по расчёту](calculation.md).

Начните с титульной страницы П01. Кнопка «Начать» откроет главное меню П02, затем «Эксперименты» — П03 с карточками нового опыта, продолжения работы и просмотра результатов. «Справка» и «О программе» открывают отдельные страницы С01 и С02; кнопка внизу возвращает в главное меню. На П04 выберите загрузку четырёх файлов либо ручной ввод. Тексты и структура П02–П04а сверены с рисунками В.4–В.7 приложения В ТЗ; полное соответствие остальных форм ещё дорабатывается.

На П07 сохранённые оценки перечислены в таблице с алгоритмом, сценарием, повтором, моделью, состоянием и итогом I(A). Поиск фильтрует строки по видимым полям; выпадающие списки ограничивают таблицу по модели и состоянию. Выберите строку и нажмите «Открыть выбранную оценку». Поиск с пустым результатом не открывает скрытую запись. Черновики продолжаются отдельным действием «Продолжить черновик».

1. **Импорт 4 файлов.** На П04 нажмите «Выбрать комплект», затем на П04а — «Выбрать папку». Папка должна содержать ровно `experiment.json`, `packets.csv`, `routes.csv`, `channels.csv`. П04а показывает назначение файлов, наличие и число записей трёх CSV из выбранного комплекта; размер и SHA-256 принятого файла доступны в подсказке к строке. Программа проверяет версию 1.0.0, формат, связи и интервалы. Отсутствующий файл отмечается в таблице; прочие ошибки показываются сообщением. До успешной проверки «Открыть данные» недоступно. После успешного выбора нажмите «Открыть данные». Если этот же комплект уже сохранён, выберите «Да», чтобы открыть найденную версию вместе с её профилем Ω, «Нет», чтобы сразу сохранить отдельную связанную копию, или «Отмена», чтобы остаться на предпросмотре. Для нового комплекта оригинальные байты сохраняются с черновиком после нажатия «Сохранить черновик».
2. **Новый.** Выберите «Открыть формы ввода»: откроется пустой П05 с паспортом и тремя пустыми таблицами. Программа не создаёт пакеты, маршруты, события или счётчики. В паспорте девять вкладок по приложению В: «Общие сведения», «Среда», «Узлы», «Соединения», «Потоки», «События», «Наблюдение», «Проверки», «Полнота». Заголовок показывает выбранную форму. Для узлов, соединений, потоков и событий таблица слева показывает основные признаки, а карточка справа редактирует выбранную запись. Кнопки над карточками добавляют, копируют, удаляют и вставляют записи. «Вставить таблицу» принимает TSV с заголовками видимых колонок либо JSON-массив полных объектов; новые строки добавляются после существующих. Кнопка в карточке записи открывает остальные поля, в том числе генерацию потока, параметры канала и изменения события. «Проверки» показывают рядом таблицы устойчивости и адаптивности; выберите строку и нажмите «Изменить» или откройте её двойным щелчком. «Полнота» показывает качество регистрации и сведения о формате; кнопка дополнительных параметров открывает таблицу полей с возможностью редактирования. Структура отдельного пропуска журналирования не определена в ТЗ, поэтому список таких пропусков редактируется как JSON без добавления придуманной схемы. Меню «Действия» в шапке содержит импорт, экспорт, историю, серии, резервное копирование и «Расширенный ввод паспорта». Ошибочное числовое значение подсвечивается и блокирует сохранение до исправления. Пустое значение хранится как `null` в JSON или как пустая ячейка CSV, наблюдавшийся ноль вводится отдельно.
   На «Общих сведениях» поля контрольной суммы, настроек и примечания к алгоритму открываются кнопкой «Настройки алгоритма и контрольная сумма» в карточке реализации; изменения сразу входят в паспорт.
3. **Таблицы.** Вкладки «Пакеты», «Маршруты» и «Каналы» показывают краткий журнал слева и все поля выбранной строки справа по П05.10–П05.12. Найдите запись поиском, выберите её и измените поле в правой карточке. Кнопки над журналом добавляют и удаляют строки, копируют и вставляют прямоугольные диапазоны через буфер обмена. `experiment_id` берётся из паспорта для всех строк и потому скрыт. Время вводится в секундах, скорость в бит/с, объём в байтах. Для маршрута перечислите направленные `link_id` по одному в строке поля «Направленные каналы по порядку»; при экспорте программа запишет их в требуемую CSV-ячейку `path_links` как JSON-массив. Пустой приём или неизмеренная очередь остаются пустыми, а не превращаются в ноль.
4. **Профиль Ω.** Вкладка П05.13 показывает семь шкал в таблице: физические опоры, единицу и направление предпочтения. Для изменения опор выберите показатель и нажмите «Изменить опоры». Кнопка «Экспертные оценки и веса» открывает П05.14: там можно ввести оценки экспертов, рассчитать веса по (3.36), отредактировать фиксированные веса, статус и основание профиля. Если профиль уже содержит фиксированные веса без экспертных векторов, экран явно показывает их отсутствие; экспертные оценки не подставляются. Кнопка «Выбрать профиль» загружает согласованный JSON-файл, «Создать копию» даёт отдельный ID для правок. Для синтетических контрольных опытов доступен `configs/examples/profile_demo.json`; его шкалы не предназначены для оценки реальных измерений. Новый черновик содержит пустой профиль; «Проверить данные» и «Запуск расчёта» сообщат, если он не заполнен. Профиль сохраняется вместе с черновиком, а его версия меняется только при изменении содержимого.
5. **Проверка и сохранение.** «Проверить данные» показывает код, место, поле и причину ошибки. Неполный набор можно сохранить черновиком, закрыть программу и восстановить через «Открыть черновик». Каждое сохранение создаёт новую версию; старые версии остаются в хранилище. При выходе с несохранёнными правками предлагается сохранить, уйти без сохранения или отменить действие.
6. **Экспорт 4 файлов.** Выберите пустую папку. Экспорт доступен для данных без блокирующих ошибок; паспорт записывается последним. Для ручного или исправленного импортированного набора `data_origin` становится `manual_prepared`; первоначальные импортированные байты остаются в хранилище черновика.

Черновики GUI по умолчанию находятся в `~/.opd/drafts.sqlite3`. Не следует вручную менять этот файл во время работы приложения. Используйте пункты «Создать резервную копию» и «Восстановить копию» в меню «Действия»; восстановление проверяет файл перед заменой текущего хранилища.

Паспорт представлен формами, повторяемые объекты — списком и деталями; пакеты, маршруты, каналы и профиль Ω открываются отдельными предметными формами. Светлые фоны закреплены и при тёмной системной теме. Композиция П05.3–П05.6 и П05.8–П05.9а предварительно сопоставлена с рисунками В.12–В.17 и В.21–В.24 на Linux Qt offscreen. Окончательная сверка на Windows и проверка крупной реальной выгрузки ещё требуются.
